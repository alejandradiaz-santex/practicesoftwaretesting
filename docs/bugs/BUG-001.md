# BUG-001: La UI muestra "Unknown error" cuando /payment/check responde 422 con errores por campo

**Severidad**: Media

## Pasos

1. Agregar un producto al carrito desde el catálogo.
2. Continuar como guest hasta Billing Address, completar con AR / C1425 / 123 y avanzar a Payment.
3. Elegir `credit-card`, dejar todo vacío y pulsar "Check payment" una vez.

## Resultado esperado

La pantalla muestra un mensaje por cada campo inválido (número de tarjeta, vencimiento, CVV y titular).

## Resultado actual

POST `/payment/check` responde 422 con el detalle por campo, pero la pantalla solo muestra "Unknown error" en `[data-test=payment-error-message]`.

## Evidencia

- POST `/payment/check` → 422 con `payment_details.credit_card_number`, `expiration_date`, `cvv` y `card_holder_name`.
- `tests/Critical Cases/tc-005-checkout-invalido.spec.ts:69-83`
