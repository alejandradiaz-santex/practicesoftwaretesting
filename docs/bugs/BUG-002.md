# BUG-002: El sitio acepta un código postal inválido ("ZZZZ") y deja avanzar

**Severidad**: Media

## Pasos

1. Llegar a Billing Address como guest.
2. Elegir país AR, código postal `ZZZZ`, número de casa `123`.

## Resultado actual

GET `/postcode-lookup` responde 200, se autocompletan street, city y state, no hay mensaje de error y el botón `proceed-3` queda habilitado.

## Evidencia

- GET `/postcode-lookup` → 200 con datos aleatorios para un código inválido.
